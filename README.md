# En SPA-hemsida för ett SPA 🧖 
- React + TypeScript + Vite.
- Gruppuppgift: Spa med SPA, 10 Yhp.
- Skapad av: Sabina, Sonny, Danny, Melker och Fabian!

## Installation och uppstart lokalt
```bash
git clone git@github.com:trixxyy-cloner/SpaApplikation.git
```
```bash
cd SpaApplikation
```
```bash
npm install
```
```bash
npm run dev
```
